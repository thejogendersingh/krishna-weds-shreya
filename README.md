# Krishna & Shreya - Wedding Invitation (1:1 Web Invitation)

Interactive wedding invitation web app with animations, audio, and countdown.

## Structure

- `index.html`: Main HTML entry point with metadata, Google Fonts, and assets.
- `assets/`:
  - `index-BgkQTLfu.js`: Application logic and UI interactions.
  - `index-BC6_D4MB.css`: Complete styling, animations, and Tailwind design tokens.
  - `envelop-sr7wwrnc.png`: Opening envelope artwork.
  - `ks-logo.png`: Couple monogram/seal logo on envelope.
  - `mainbg-C1qdEah8.jpg`: High-resolution background texture.
  - `event1.png`: Mangal Paath celebration artwork.
  - `haldi.png`: Haldi Carnival celebration artwork.
  - `bhaat.png`: Bhaat ceremony celebration artwork.
  - `sanget-Bz6_t-zi.png`: Sangeet illustration.
  - `phere-LBZBKn6h.png`: Phera ceremony illustration.
  - `recept-CMr8tXBs.jpg`: Reception celebration artwork.
- `audio/`:
  - `background.mp3`: Background wedding instrumental music.
- `vercel.json`: Vercel static routing configuration.
- `package.json`: Project scripts.

## How to Run Locally

```bash
npm start
```
Then open: `http://localhost:3000`

## Vercel Deployment

Zero configuration required. Vercel automatically deploys the static files using `vercel.json`.
